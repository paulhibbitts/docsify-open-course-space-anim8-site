# Modules

## [Module 1 - Basic 2D Objects](module-1-basic-2d-objects.md) <!-- {docsify-ignore} -->

We'll be using Adobe Animate to create a simple animation in order to get familiar with the software the workspace. In addition, we'll be starting to build a very simple 2D animation.

## [Module 2 - Beyond Basic 2D Animation](module-2-beyond-basic-2d-animation.md) <!-- {docsify-ignore} -->

At this point you should have a basic understanding of how to draw objects and backgrounds in Animate and how to create simple animations using Motion Tweens.

</div>

<div class="card">

## [Module 3 - Final Project](module-3-final-project.md) <!-- {docsify-ignore} -->

In this final assignment you're going to bring together everything that you've learned over the course of this class - motion tweens, frame by frame animation, using graphic symbols and movie clips, and adding sound to an animation. You may work with one partner for this project.

</div>
